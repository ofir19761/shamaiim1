# Shamaiim1

בנה אתר מיתוג, ייעוץ עסקי ומתחם ספר דיגיטלי יוקרתי בעברית מלאה (RTL) עבור:
"שמיים — ייעוץ עסקי, פיתוח עסקי ופיננסי" בהובלת אופיר לוי.

עקרונות המערכת:
האתר הוא נכס דיגיטלי שלם ומאוחד המשלב בין פעילות הייעוץ העסקי לבין ספרו של אופיר לוי, "ערך מוסף — מדריך מעשי ליזמים ובעלי עסקים". כל עמודי הספר מוטמעים ישירות כחלק אינטגרלי מהאתר (ללא הפניה לאתר חיצוני וללא iframes), לחוויית גלישה רציפה (Seamless) ומיקסום SEO.

קו עיצובי ושפה ויזואלית:
- פלטת צבעים ("שמיים קלאסי"): כחול נייבי עמוק (#0B192C) לסמכות ויציבות, כחול סלייט (#1E3E62) לאלמנטים משניים, נגיעות זהב חם ויוקרתי (#D4AF37) להדגשות ו-CTA, ורקע קרם פנינה חם ומזמין (#F9F8F6) לקריאות מקסימלית.
- טיפוגרפיה: כותרות אלגנטיות בגופן סריפי (Frank Ruhl Libre), טקסט רץ נקי וקריא (Assistant).
- עיצוב נקי, בוטיקי ומכובד שמשדר ידע, ניסיון ושקט פיננסי.

השתמש במידע והתוכן האותנטי של אופיר לוי:
- ניסיון: מעל 20 שנה בייעוץ עסקי וניהול כספים בכיר בחברות מובילות (Lee Cooper Jeans, ארומה תל אביב, Sack's).
- המלצת לקוח בולטת (Testimonial):
  "אופיר עבד בארגונים גדולים, הוא בעל ניסיון רב, מכיר לעומק את העסק שלי ומסתכל מגבוה. הוא רואה את התמונה המלאה. עם אופיר אני מתנהל כמו עסק גדול בעסק קטן: אני מקבל ממנו ייעוץ בכל מה שקשור לניהול העסק ופיננסים, ולא זז מילימטר בלעדיו. אופיר יודע לתמוך בי בכל שלב, הוא מכיר את העסק שלי כל כך טוב, ממש כמוני. אני בוטח בו ויודע שיחד נגיע רחוק" — יגל שמעיה, מייסד ומנכ"ל גולד פארם (מוצרים לגיל השלישי).

ארכיטקטורת האתר והנתיבים:
1. סרגל עליון קבוע (Header):
   - לוגו טקסטואלי אלגנטי: "שמיים | ייעוץ עסקי ופיננסי".
   - קישורי ניווט: שירותים, אודות, הספר: ערך מוסף (קישור פנימי למתחם הספר), מאמרים, צור קשר.
   - כפתור CTA בזהב: "לתיאום פגישת היכרות".
2. דף הבית (נתיב `/`):
   - Hero עוצמתי עם כותרת, תת-כותרת, כפתור CTA מהיר לטופס ("בוא נדבר") וכפתור לקריאת הספר אונליין.
   - 4 תחומי שירות עיקריים (כרטיסים אינטראקטיביים עם אייקונים יוקרתיים):
     1. פיתוח עסקי ואסטרטגיה
     2. ליווי וניהול פיננסי
     3. הכוונה וליווי ליזמים
     4. תוכן ויצירת ערך
   - אזור אודות מורחב על אופיר לוי, כולל תחנות המפתח המרשימות (לי קופר, ארומה ת"א, סאקס) ומסגרת לתמונת פרופיל.
   - חלון ראווה מרהיב לספר "ערך מוסף": הדמיה תלת-ממדית מעוצבת של כריכת הספר, ציטוט השראה, תקציר וכפתור מעבר למתחם הספר.
   - עדויות לקוחות (הציטוט של יגל שמעיה מגולד פארם).
   - מאגר מאמרים נבחרים (כרטיסי תוכן מקצועיים מבוססי המאמרים הקיימים: תזרים מזומנים, ניהול עסק מצליח, שותפויות עסקיות ועוד).
   - טופס יצירת קשר מעוצב (שם פרטי, שם משפחה, טלפון, אימייל, הודעה) עם משוב שליחה יפהפה.
   - פוטר עשיר ומכובד עם פרטי הקשר, קישורים פנימיים וזכויות יוצרים.
3. מתחם הספר הדיגיטלי המלא:
   - ממשק קריאה ייעודי, נקי ונטול הסחות דעת, כולל סרגל חזרה לאתר שמיים וקפיצה בין פרקים:
     * עמוד שער ותקציר הספר (`/book`)
     * תוכן עניינים מפורט עם זמני קריאה משוערים (`/book/toc`)
     * פתח דבר (`/book/preface`)
     * פרק א׳: מערכות יחסים בסביבה העסקית (`/book/chapter-1`)
     * פרק ב׳: תהליך המכירה והובלת עסקאות (`/book/chapter-2`)
     * פרק ג׳: ניהול משא ומתן כמנוף לצמיחה (`/book/chapter-3`)
     * פרק ד׳: שימור לקוחות ויצירת נאמנות ארוכת טווח (`/book/chapter-4`)
     * הרזומה והמחבר: פרופיל מקצועי מורחב על אופיר לוי (`/book/resume`)
   - בכל פרק: ניווט מהיר לפרק הבא/הקודם וחזרה לאתר הראשי. טקסטים עשירים ומקצועיים בכל פרק.
